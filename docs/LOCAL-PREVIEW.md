تشغّل نسخة كاملة على جهازك فقط (127.0.0.1):
- الموقع الحقيقي (Vite) بإعدادات المحاكي.
- Worker الطلبات الحقيقي بالسياسة النهائية: `STOCK_POLICY=on_delivery` و`APPROVAL_MODE=off`. يعني: قبول تلقائي، حجز عند الطلب، خصم عند التسليم فقط.
- قاعدة بيانات ومصادقة محليتان (Firebase Emulator، مشروع `demo-`).
- منتجات تجريبية.
- إشعارات Telegram تذهب إلى مستقبِل محلي، بلا أزرار.
- الشراء كزائر مفعّل.
- الدولاب غير مفعّل.

بعد دقيقة إلى دقيقتين يطبع:

```

[inner] site (guest checkout on):  http://127.0.0.1:3000/#/
[inner] admin dashboard:           http://127.0.0.1:3000/#/login   e-mail m***@… (the dashboard admin address)   password e2e-…
[inner] STOP the preview:          http://127.0.0.1:<port>/
```

- **الموقع:** افتح `http://127.0.0.1:3000/#/` في المتصفح. للهاتف استخدم وضع الجوال في أدوات المطوّر (F12 ← Ctrl+Shift+M).
- **لوحة التحكم:** `http://127.0.0.1:3000/#/login`، بالبريد المطبوع (عنوان المدير المعرّف في الموقع) وكلمة المرور المطبوعة. الحساب موجود في المحاكي المحلي فقط، وكلمة المرور جديدة في كل تشغيل.
- **الإيقاف:** افتح رابط STOP المطبوع، أو انتظر 180 دقيقة (يمكن تغييرها بـ `$env:E2E_PREVIEW_MINUTES='60'`). الإيقاف بهذا الرابط ينظّف كل العمليات. لا تغلق النافذة بالقوة، كي لا تبقى عمليات المحاكي تعمل.

## سيناريو التجربة المقترح

1. أضف منتجًا إلى السلة، ثم «إتمام الطلب» كزائر ← صفحة نجاح الطلب.
2. في اللوحة ← «إدارة الطلبات»: الطلب «جديد»، والمخزون محجوز وغير مخصوم.
3. «بدء التجهيز» ثم «تم الشحن»: المخزون لا يتغيّر.
4. «تم التسليم»: يُخصم مرة واحدة. الضغط مرة ثانية لا يخصم مجددًا.
5. طلب آخر يُلغى قبل التسليم: يُحرَّر الحجز ولا خصم.
6. طلب مُسلَّم ← إرجاع: لا يتم إلا بتأكيد، ويعود المخزون مرة واحدة.
